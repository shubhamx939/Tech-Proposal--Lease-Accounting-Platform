What I understood about your work

The Activity at the Center of This

Before proposing anything, I want to show you I've understood exactly what you do — because the whole point of a tech solution is that it should replace or accelerate the manual Excel grind, not add another layer of complexity on top of it.

The Core Task: Ind AS 116 Lease Accounting for CultFit-type clients

Every time your client signs a lease — a gym, office, retail space — you build and maintain a working that computes the following under Ind AS 116:

01 / Input
Lease master data
Location, lessor, city, lease start & end, rent, CAM, deposit, escalation %, lock-in, fit-out period, IBR
02 / Engine
Amortisation schedule
Month-by-month PV calculation. Interest = (Opening LL − Payout) × IBR/12. Closing LL rolls forward per period
03 / Output
Annual P&L + BS entries
Depreciation, interest, lease liability (current/non-current), ROU asset WDV — per lease, per FY, per entity
04 / Events
Modifications & exits
Remeasure LL on modification. ROU reversal + LL write-off on termination/shutdown. Rent concession tracking
05 / Rollup
Lead sheet consolidation
200+ leases aggregated. Month-wise rent schedule. FY-wise depreciation, interest, payout by zone and entity
06 / Report
Final audit deliverable
Consolidated ROU + LL roll-forward, maturity profile (<1yr / 1–5yr / >5yr), entity-wise split, variance checks

Key pain points in the current Excel approach

One new lease = manually create a new sheet, copy formulas, update Lead Sheet row. Prone to formula breaks.

200+ sheets in one workbook — the file is massive, slow, and crashes risk corrupting months of work.

A termination or modification requires manual intervention across the individual sheet and the Lead Sheet simultaneously.

The report (maturity profile, roll-forward, entity split) has to be manually assembled from the Summary sheet every quarter.

No audit trail — if a number changes, you cannot tell who changed it or why. No version history beyond file copies.

Client data is sitting in an unprotected Excel file on a local machine. No access control, no backup discipline.

The Three Plans
Plan 01 — Lean

The Single-Purpose Tool

Replace the Excel workbook with a fast, reliable web dashboard. Nothing more, nothing less.

₹35k – 50k
One-time development
6 – 8 weeks delivery

This is a tight, focused build. The philosophy is: take exactly what you do in that 250-sheet Excel workbook and rebuild it as a proper web application — with a database, a clean UI for data entry, and auto-generated outputs. No bells, no whistles. Just the core job, done reliably.

What gets built

  • Secure login with client-level data isolation
  • Lease master data entry form (all fields: location, lessor, dates, rent, CAM, deposit, escalation, IBR)
  • Auto-computed amortisation schedule (PV calculation engine same as your Excel logic)
  • FY-wise P&L and Balance Sheet output: depreciation, interest, LL (current + non-current), ROU WDV
  • Termination and modification workflows — date-triggered remeasurement
  • Rent concession recording per period
  • Consolidated Lead Sheet view — all leases in one table, filterable by city / zone / status
  • Auto-generated maturity profile (<1yr, 1–5yr, >5yr)
  • Export to Excel — structured output ready to paste into audit report

What is NOT in this plan

  • No multi-client login panel (single client only)
  • No in-app report generation / PDF output
  • No document upload (lease agreements)
  • No billing or payment integration
  • No mobile app

Technology stack

React Node.js PostgreSQL Render / Railway JWT Auth ExcelJS

Hosted on cloud. No installation needed on your machine. Accessible from browser.

What changes for you day-to-day

Adding a new lease takes 3 minutes in a form instead of 30 minutes of Excel sheet duplication. Terminations are handled by clicking a date — the app remeasures everything automatically. Your quarterly output (depreciation + LL roll-forward + maturity profile) is available at one click, not a 2-hour assembly job. The file-crash risk disappears. Your data is in a proper database with daily backups.

Honest note from my side

At ₹35k–50k this is priced lean on purpose. It will serve you well if you have one primary client running this activity. If your practice grows to 3–5 clients running the same activity, you will outgrow this within a year and need the Balanced plan anyway. So treat this as a "start now, validate the idea" option — not a long-term architecture.
